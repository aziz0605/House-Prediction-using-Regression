# 🏠 House Price Prediction Using Linear Regression

## 📌 Project Overview

This project focuses on predicting house prices using **Machine Learning – Linear Regression**.

The model predicts house prices based on three important features:
- Area of the house
- Number of bedrooms
- Age of the house

The project uses Python and Scikit-learn to train a Linear Regression model and predict house prices.

## 🎯 Objectives

- To understand the concept of Linear Regression.
- To predict house prices using Machine Learning.
- To train and test a regression model.
- To evaluate model performance using the R² Score.
- To visualize actual vs predicted house prices.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## 📊 Dataset Description

The dataset contains house-related information.

| Feature | Description |
|---|---|
| area | Area of the house |
| bedrooms | Number of bedrooms |
| age | Age of the house |
| price | House price (Target Variable) |

## ⚙️ Project Workflow

1. Import the required Python libraries.
2. Load the house price dataset.
3. Select input features (Area, Bedrooms, Age).
4. Select the target variable (Price).
5. Split the dataset into training and testing sets.
6. Train the Linear Regression model.
7. Predict house prices using the trained model.
8. Evaluate the model using R² Score.
9. Visualize actual vs predicted house prices.

## 🤖 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values based on input features.

The model learns the relationship between house features and house prices.

## 📈 Model Evaluation

The model performance is evaluated using:

- R² Score (Coefficient of Determination)

The R² Score helps measure how well the model explains the variation in house prices.
